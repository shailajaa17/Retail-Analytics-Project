# Retail Analytics Using Python

## Project Overview
This project focuses on end-to-end retail data analytics using Python. It explores sales performance, customer purchasing behavior, product trends and business insights using real-world e-commerce transaction data.

## Dataset
- **Dataset:** Online Retail II
- **Source:** UCI Machine Learning Repository
- **Format:** Excel (.xlsx)
- **Period analyzed:** 2010–2011

[Download Dataset](https://archive.ics.uci.edu/ml/machine-learning-databases/00502/online_retail_II.xlsx)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Analysis
- Retail transaction analysis
- Sales and revenue analysis
- Customer analysis and segmentation
- Product performance analysis
- Daily and monthly sales trends
- Seasonality analysis
- Market basket analysis
- Moving average analysis
- Data visualization
- Business recommendations

## Key Objectives
- Understand customer purchasing patterns.
- Identify top-performing products and categories.
- Analyze revenue trends over time.
- Discover relationships between purchased products.
- Generate meaningful business insights.

## Project Files
- `retailtask4.ipynb` – Complete Python analysis and visualizations.
- `README.md` – Project documentation.

## Conclusion
This project demonstrates how Python-based data analytics can help businesses understand sales trends, customer behavior and product performance to support data-driven decisions.
